JOHN SOLOMON — PORTFOLIO WEBSITE
================================

WHAT TO UPLOAD TO GITHUB
Upload everything in this folder (index.html, 404.html, README.txt and the
assets folder) to the top level of your GitHub repository. Drag them from
Finder onto GitHub's upload page so the folders are kept.

CHANGING YOUR VIDEOS / TEXT
Everything about your projects lives in  assets/js/config.js
• video:   paste a YouTube link (normal, youtu.be or Shorts)
• Shorts links open in a tall 9:16 player automatically
• linkedin: replace the placeholder with your real LinkedIn URL —
  the LinkedIn link in the footer stays hidden until you do.
• accent:  optional, e.g.  accent: "#ff8a3d"  sets a project's glow colour

UPDATING THE SITE LATER
Edit or re-upload the changed file on GitHub. The live site updates in
about a minute.
